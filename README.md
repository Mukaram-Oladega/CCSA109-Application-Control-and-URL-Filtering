
# CCSA109 – Application Control and URL Filtering

## Overview

This repository contains my completed CCSA109 Module 9 theory assignment on Application Control and URL Filtering.

The assignment explores how Check Point Application Control and URL Filtering enhance network security by providing visibility and control over application usage and website access.
